# AI-Script 品牌标识规范

## Logo 设计说明

以**光流神经元**为核心意象，表现 AI 神经网络驱动视频创作的动态过程。

- **中心节点**：代表 AI 核心引擎
- **放射状神经元**：代表数据在多模态（文本/图像/视频/音频）间的流转
- **脉冲光点**：代表生成过程中的实时计算与反馈
- **配色**：青色(#06B6D4)到紫色(#A855F7)渐变，传达科技感与创造力

---

## 文件清单

| 文件 | 尺寸 | 使用场景 |
|---|---|---|
| `logo-icon.svg` | 200x200 | 网站 favicon、App 图标、头像、小尺寸展示 |
| `logo-icon-light.svg` | 200x200 | 浅色背景页面（如白色底文档、PPT） |
| `logo-icon-mono.svg` | 200x200 | 水印、印章、单色打印、激光雕刻 |
| `logo-horizontal.svg` | 480x120 | 网站顶部导航栏、邮件签名、横版banner |
| `logo-vertical.svg` | 240x320 | 登录页、启动页、竖版海报、展会展板 |

---

## 配色规范

| 用途 | 色值 | 说明 |
|---|---|---|
| 主色-青 | `#06B6D4` | 中心节点、脉冲光点 |
| 主色-紫 | `#6366F1` | 中层线路、外环 |
| 辅色-洋红 | `#A855F7` | 渐变终点、高光 |
| 深色背景 | `#0F172A` | 图标圆形底色 |
| 浅色背景 | `#F8FAFC` | 浅色版图标底色 |
| 文字深色 | `#0F172A` | 浅色背景上的标题文字 |
| 文字浅色 | `#F8FAFC` | 深色背景上的标题文字 |

---

## 使用禁忌

- 不要拉伸或压缩 Logo 的宽高比例
- 不要更改神经元网络的节点数量（6个中层 + 6个外层）
- 不要使用非规范配色（如红色、绿色、橙色等）
- 不要在过于复杂的背景上使用带背景圆的版本
- 单色版不要添加渐变色

---

## 前端集成建议

```html
<!-- 网站 favicon -->
<link rel="icon" type="image/svg+xml" href="/logo-icon.svg"/>

<!-- 顶部导航栏 -->
<img src="/logo-horizontal.svg" alt="AI-Script" height="40"/>

<!-- 登录页 -->
<img src="/logo-vertical.svg" alt="AI-Script" width="180"/>

<!-- 水印 -->
<img src="/logo-icon-mono.svg" alt="AI-Script" width="80" opacity="0.15"/>
```
