## 1. 产品概述

### 1.1 这是什么平台

AI-Script 是一款面向内容创作者和视频运营团队的 **AI 智能视频生成平台**。您只需要提供文字剧本或创意想法，平台就能自动帮您完成从剧本分集、画面分镜、图片生成、短视频制作到最终成片合成的完整流程。

### 1.2 面向谁使用

| 用户类型 | 使用场景 |
|---------|---------|
| 短视频创作者 | 批量生成抖音/快手/视频号内容 |
| 品牌营销团队 | 制作产品宣传视频、广告片 |
| 教育机构 | 生成教学动画、知识科普视频 |
| 自媒体运营 | 日更视频内容，提升产出效率 |
| 电商卖家 | 制作商品展示视频、带货短视频 |

### 1.3 核心能力

- **AI 智能分集**：输入一个完整剧本，AI 自动拆分成多集脚本
- **提示词自动生成**：为每一集自动生成画面描述提示词
- **智能分镜**：将提示词转化为具体的分镜画面规划
- **AI 绘图**：调用 Image 模型生成高质量画面
- **AI 视频生成**：将图片转化为动态短视频
- **一键合成**：FFmpeg 自动合成带音轨的完整视频
- **实时进度推送**：通过 WebSocket 实时查看任务执行进度

### 1.4 工作流程概览

```
创建项目 → 创建剧本 → AI分集 → 生成提示词 → 创建分镜 → 应用风格
                                                              ↓
合成完整视频 ← 生成短视频 ← 生成图片 ← 生成分镜画面 ← 批量保存分镜
```

## 2. 快速开始

### 2.1 首次使用流程（5分钟上手）

#### 步骤 1：登录系统

1. 打开浏览器，访问平台地址（由管理员提供）
2. 在登录页面输入您的 **用户名** 和 **密码**
3. 点击【登录】按钮
4. 首次登录后建议立即修改密码

> 提示：如果忘记密码，请联系系统管理员重置。

#### 步骤 2：创建您的第一个项目

1. 登录后进入首页，点击左侧菜单【项目管理】
2. 点击页面右上角的【新建项目】按钮
3. 填写项目信息：
   - **项目名称**：给项目起个名字（如"夏季新品推广"）
   - **项目描述**：简要说明项目内容（可选）
4. 点击【确定】创建项目

#### 步骤 3：创建剧本

1. 进入刚创建的项目详情页
2. 点击【剧本管理】标签
3. 点击【新建剧本】
4. 填写剧本信息：
   - **剧本标题**：如"夏日清凉饮品广告"
   - **剧本内容**：输入完整的文字剧本
5. 点击【保存】

#### 步骤 4：AI 智能分集

1. 在剧本列表中找到刚创建的剧本
2. 点击【AI 分集】按钮
3. 系统会自动将剧本拆分成多个分集
4. 等待任务完成（通常需要 1-3 分钟）
5. 刷新页面查看分集结果

#### 步骤 5：生成提示词

1. 点击进入某个分集的详情页
2. 点击【生成提示词】按钮
3. AI 会自动为当前分集生成画面描述提示词
4. 您可以编辑修改提示词内容

#### 步骤 6：创建分镜

1. 进入【分镜管理】页面
2. 点击【新建分镜】
3. 选择对应的分集和提示词
4. 填写分镜信息（镜头描述、时长等）
5. 点击【保存】

#### 步骤 7：生成图片

1. 在分镜列表中，选择要生成图片的分镜
2. 点击【生成图片】按钮
3. 选择要使用的 Image 模型
4. 等待 AI 生成图片（约 30 秒 - 2 分钟）

#### 步骤 8：生成短视频

1. 图片生成完成后，点击【生成视频】
2. 选择 Video 模型
3. 等待视频生成完成

#### 步骤 9：合成完整视频

1. 进入【视频合成】页面
2. 选择要合成的所有短视频片段
3. 点击【开始合成】
4. 系统会自动拼接所有片段并添加音轨

#### 步骤 10：下载成品

1. 合成完成后，在【完整视频】列表中找到成品
2. 点击【下载】按钮即可获取最终视频文件

**操作步骤**：
1. 输入用户名

3. 点击【登录】

**入口**：页面右上角头像下拉菜单

1. 点击右上角头像
2. 选择【退出登录】

## 6. AI模型管理

### 6.1 模型列表

**入口**：左侧菜单【模型管理】（需要管理员权限）

**页面说明**：
- 显示平台已注册的所有 AI 模型
- 按模型类型分类：文本（Text）、图片（Image）、视频（Video）、音频（Audio）

### 6.2 注册新模型

**操作步骤**：
1. 进入【模型管理】页面
2. 点击【注册模型】
3. 填写模型信息：
   - **模型名称**：如"GPT-4o"、"Stable Diffusion XL"
   - **模型类型**：选择 text / image / video / audio
   - **模型标识**：模型在网关中的唯一标识
   - **提供商**：如 OpenAI、阿里云、自定义等
   - **网关地址**：LiteLLM 网关的调用地址
   - **API Key**：调用模型所需的密钥
   - **参数配置**：默认生成参数（温度、最大 Token 等）
4. 点击【保存】

**预期结果**：模型注册成功，可在创作流程中选择使用。

### 6.3 模型健康检查

**操作步骤**：
1. 在模型列表中找到目标模型
2. 点击【健康检查】按钮
3. 系统会发送测试请求验证模型可用性

**预期结果**：
- 绿色状态：模型正常运行
- 红色状态：模型连接异常，请检查配置

### 6.4 编辑/删除模型

- **编辑**：点击【编辑】修改模型配置信息
- **删除**：点击【删除】移除模型注册（不影响已生成的内容）

## 7. 视频创作流水线

### 7.1 剧本管理

#### 7.1.1 剧本列表

**入口**：进入项目详情 → 【剧本管理】标签

**页面说明**：
- 显示项目下的所有剧本
- 显示剧本状态：草稿、已分集、已完成

#### 7.1.2 创建剧本

**操作步骤**：
1. 进入项目【剧本管理】
2. 点击【新建剧本】
3. 填写剧本表单：
   - **剧本标题**（必填）：如"品牌故事宣传片"
   - **剧本内容**（必填）：输入完整的文字剧本内容
     - 支持多段落输入
     - 建议包含场景描述、人物对话、旁白等内容
   - **备注**（可选）：补充说明
4. 点击【保存】

**预期结果**：剧本创建成功，状态为"草稿"。

#### 7.1.3 编辑剧本

**操作步骤**：
1. 在剧本列表中点击【编辑】
2. 修改剧本标题或内容
3. 点击【保存】

> 注意：如果剧本已经执行过 AI 分集，修改内容后可能需要重新分集。

#### 7.1.4 AI 智能分集

**功能说明**：将完整的剧本自动拆分成多个独立的分集（场景/段落），每个分集对应视频中的一个片段。

**操作步骤**：
1. 在剧本列表中找到目标剧本
2. 确认剧本内容已保存
3. 点击【AI 分集】按钮
4. 在确认弹窗中点击【确定】
5. 系统提交异步任务，页面显示"分集中..."

**查看进度**：
- 分集任务在后台异步执行
- 您可以离开页面做其他操作
- 稍后刷新页面查看结果

**预期结果**：
- 剧本状态变为"已分集"
- 点击剧本标题进入详情，可看到多个分集
- 每个分集包含：分集标题、分集内容、序号

#### 7.1.5 手动管理分集

**添加分集**：
1. 进入剧本详情页
2. 点击【添加分集】
3. 填写分集标题和内容
4. 点击【保存】

**编辑分集**：
1. 在分集列表中点击【编辑】
2. 修改分集内容
3. 点击【保存】

**删除分集**：
1. 在分集列表中点击【删除】
2. 确认删除操作

### 7.2 提示词管理

#### 7.2.1 什么是提示词

提示词（Prompt）是用于指导 AI 生成画面的文字描述。例如：

> "一个阳光明媚的海滩，金色的沙滩上有五彩的遮阳伞，远处是碧蓝的大海，4K 高清，电影级画质"

#### 7.2.2 生成提示词

**入口**：进入分集详情页 → 【提示词】标签

**操作步骤**：
1. 进入目标分集的详情页
2. 点击【生成提示词】按钮
3. 系统根据分集内容调用 LLM 模型自动生成画面描述
4. 等待任务完成（约 30 秒 - 1 分钟）
5. 刷新页面查看生成的提示词

**预期结果**：
- 生成一条或多条提示词
- 每条提示词包含：画面描述文字、适用场景说明

#### 7.2.3 编辑提示词

**操作步骤**：
1. 在提示词列表中点击【编辑】
2. 修改提示词内容
3. 点击【保存】

**优化建议**：
- 描述要具体（颜色、光线、构图、风格）
- 可以指定画质关键词（4K、高清、电影级）
- 可以指定艺术风格（赛博朋克、水墨画、油画）

#### 7.2.4 删除提示词

1. 在提示词列表中点击【删除】
2. 确认删除

### 7.3 分镜管理

#### 7.3.1 什么是分镜

分镜（Storyboard）是视频制作中的画面规划，将剧本的每个场景细化为具体的镜头画面。一个分集通常包含多个分镜。

#### 7.3.2 创建分镜

**入口**：进入项目 → 【分镜管理】标签

**操作步骤**：
1. 点击【新建分镜】
2. 填写分镜信息：
   - **所属分集**：选择关联的分集
   - **分镜标题**：如"开场全景"
   - **镜头描述**：画面的具体内容描述
   - **提示词**：选择或输入用于生成画面的提示词
   - **镜头时长**：该镜头在视频中的持续时间（秒）
   - **镜头类型**：远景/全景/中景/近景/特写
   - **排序序号**：分镜的先后顺序
3. 点击【保存】

**预期结果**：分镜创建成功，出现在分镜列表中。

#### 7.3.3 批量保存分镜

**功能说明**：一次性创建多个分镜，提高效率。

**操作步骤**：
1. 点击【批量创建】
2. 在表格中填写多个分镜的信息
3. 每行代表一个分镜
4. 点击【批量保存】

#### 7.3.4 应用风格

**功能说明**：将风格库中的视觉风格应用到分镜上，统一画面风格。

**操作步骤**：
1. 在分镜列表中选择要应用风格的分镜（可多选）
2. 点击【应用风格】
3. 在弹窗中选择风格模板
4. 点击【确定】

**预期结果**：选中的分镜关联了指定风格，生成图片时会应用该风格的视觉特征。

#### 7.3.5 编辑/删除分镜

- **编辑**：点击【编辑】修改分镜信息
- **删除**：点击【删除】移除分镜

**入口**：左侧菜单【风格库】

**页面说明**：
- 显示平台所有可用的视觉风格模板
- 包含系统预设风格和用户自定义风格

#### 7.4.2 创建风格

**操作步骤**：
1. 进入【风格库】
2. 点击【新建风格】
3. 填写风格信息：
   - **风格名称**：如"赛博朋克风"、"清新日系"
   - **风格描述**：说明该风格的特点
   - **风格提示词**：定义风格的核心提示词
     - 例如："cyberpunk style, neon lights, futuristic city"
   - **参考图片**（可选）：上传风格参考图
4. 点击【保存】

**预期结果**：风格创建成功，可在分镜管理中应用。

#### 7.4.3 编辑/删除风格

- **删除**：移除自定义风格（系统预设风格不可删除）

### 7.5 图片生成

#### 7.5.1 生成分镜图片

**入口**：进入分镜详情页 或 分镜列表

**操作步骤**：
1. 找到目标分镜
2. 确认分镜已关联提示词
3. 点击【生成图片】按钮
4. 在弹窗中选择：
   - **Image 模型**：如 Stable Diffusion、DALL-E 等
   - **图片尺寸**：如 1024x1024、1920x1080
   - **生成数量**：1-4 张
5. 点击【开始生成】

**查看进度**：
- 页面显示生成进度
- 也可以通过 WebSocket 实时推送查看状态

**预期结果**：
- 生成指定数量的图片
- 图片自动保存到分镜下
- 可以在分镜详情中查看和选择

#### 7.5.2 重新生成图片

如果对生成结果不满意：
1. 在分镜详情中找到已生成的图片
2. 可以修改提示词后再次点击【生成图片】
3. 或点击单张图片的【重新生成】

#### 7.5.3 选择最终图片

**操作步骤**：
1. 在分镜详情中查看所有生成的图片
2. 点击选中要使用的图片（会显示选中标记）
3. 被选中的图片将用于后续视频生成

### 7.6 短视频生成

#### 7.6.1 基于图片生成视频

**入口**：分镜详情页 或 【短视频】页面

**操作步骤**：
1. 确保分镜已生成并选中了最终图片
2. 点击【生成视频】按钮
3. 在弹窗中选择：
   - **Video 模型**：如 Runway、Pika、Stable Video Diffusion 等
   - **视频时长**：3 秒 / 5 秒 / 10 秒
   - **运动强度**：轻微 / 中等 / 强烈
4. 点击【开始生成】

**预期结果**：
- 系统调用 Video 模型将图片转化为动态视频
- 生成的短视频保存到分镜下
- 时长通常为 3-10 秒

#### 7.6.2 查看生成状态

- 生成过程中显示进度条
- 生成完成后可预览视频
- 支持下载单个短视频片段

### 7.7 完整视频合成

#### 7.7.1 合成设置

**入口**：项目详情 → 【视频合成】标签

**操作步骤**：
1. 进入【视频合成】页面
2. 系统显示所有已生成短视频的分镜
3. 选择要合成的分镜（按顺序勾选）
4. 设置合成参数：
   - **输出分辨率**：720p / 1080p / 4K
   - **帧率**：24fps / 30fps / 60fps
   - **转场效果**：无 / 淡入淡出 / 滑动
   - **背景音乐**（可选）：上传音频文件或选择系统音乐
5. 点击【开始合成】

#### 7.7.2 查看合成进度

- 合成任务异步执行
- 页面显示实时进度百分比
- 也可以通过 WebSocket 接收进度推送

#### 7.7.3 下载成品

**操作步骤**：
1. 合成完成后，在【完整视频】列表中找到成品
2. 点击【预览】可在线观看
3. 点击【下载】保存到本地

**输出格式**：MP4（H.264 编码）

## 8. 流水线编排

### 8.1 什么是流水线

流水线（Pipeline）是一种可自定义的自动化工作流，您可以将视频创作的各个步骤编排成自动执行的流程，实现"一键出片"。

### 8.2 流水线列表

**入口**：左侧菜单【流水线】

### 8.3 创建流水线

**操作步骤**：
1. 进入【流水线】页面
2. 点击【新建流水线】
3. 填写流水线名称和描述
4. 在可视化编辑器中配置流程：
   - 拖拽节点：剧本输入 → AI 分集 → 生成提示词 → 创建分镜 → 生成图片 → 生成视频 → 合成视频
   - 连接节点形成 DAG（有向无环图）
   - 设置每个节点的参数
5. 点击【保存】

### 8.4 执行流水线

**操作步骤**：
1. 在流水线列表中找到目标流水线
2. 点击【执行】
3. 选择输入的剧本
4. 点击【开始执行】

**查看进度**：
- 页面显示每个节点的执行状态
- 绿色：已完成
- 蓝色：执行中
- 灰色：等待中
- 红色：执行失败

### 8.5 查看执行记录

**入口**：点击流水线 → 【执行记录】标签

**可查看信息**：
- 每次执行的开始时间、结束时间
- 每个步骤的执行结果
- 失败的错误信息

## 11. 视频创作完整流程示例

### 实战演示：制作一条"夏日清凉饮品"宣传视频

#### 第 1 步：创建项目

1. 点击左侧【项目管理】
2. 点击【新建项目】
3. 填写：
   - 项目名称：`2026夏季新品-清凉果茶系列`
   - 项目描述：`为夏季新品果茶系列制作 30 秒宣传短视频`
4. 点击【确定】

#### 第 2 步：编写剧本

1. 进入项目，点击【剧本管理】
2. 点击【新建剧本】
3. 填写：
   - 剧本标题：`清凉一夏，果茶来袭`
   - 剧本内容：
     ```
     【开场】炎炎夏日，阳光炙烤着城市街道。一位年轻人擦着汗，走进一家明亮的饮品店。

     【场景一】店员微笑着递上一杯色彩缤纷的果茶。杯壁上凝结着晶莹的水珠，水果切片在茶水中漂浮。

     【场景二】年轻人接过果茶，喝下一口，表情瞬间清爽愉悦。背景仿佛有清凉的气流环绕。

     【场景三】特写镜头：新鲜的草莓、柠檬、百香果落入杯中，溅起晶莹的水花。

     【结尾】品牌 Logo 出现，配上标语"清凉一夏，从这一杯开始"。
     ```
4. 点击【保存】

#### 第 3 步：AI 智能分集

1. 在剧本列表中，点击【AI 分集】
2. 等待约 1-2 分钟
3. 刷新页面，看到剧本被拆分为 5 个分集：
   - 分集 1：开场 - 夏日街头
   - 分集 2：进店点单
   - 分集 3：品尝果茶
   - 分集 4：水果特写
   - 分集 5：品牌结尾

#### 第 4 步：生成提示词

1. 依次进入每个分集
2. 点击【生成提示词】
3. 查看 AI 生成的画面描述，例如分集 1 的提示词：
   > "夏日城市街道，阳光强烈，一位年轻人在炎热中行走，擦汗的动作，明亮的色调，4K 高清，电影级画质"
4. 根据需要微调提示词

#### 第 5 步：创建分镜

1. 进入【分镜管理】
2. 为每个分集创建 2-3 个分镜：
   - 分集 1：
     - 分镜 1.1：城市街道全景（5秒）
     - 分镜 1.2：年轻人擦汗特写（3秒）
   - 分集 2：
     - 分镜 2.1：饮品店门面（3秒）
     - 分镜 2.2：递果茶的手部特写（4秒）
   - ...以此类推
3. 使用【批量创建】提高效率

#### 第 6 步：创建并应用风格

1. 进入【风格库】
2. 点击【新建风格】
3. 创建"清新夏日风"：
   - 风格提示词：`fresh summer style, bright and vibrant colors, natural lighting, clean composition, high saturation, cheerful atmosphere`
4. 回到【分镜管理】
5. 全选所有分镜，点击【应用风格】
6. 选择"清新夏日风"

#### 第 7 步：生成图片

1. 在分镜列表中，依次点击每个分镜的【生成图片】
2. 选择 Image 模型（如 Stable Diffusion XL）
3. 设置图片尺寸为 1920x1080
4. 等待每张图片生成（约 30 秒 - 1 分钟）
5. 查看生成结果，选择最满意的图片

#### 第 8 步：生成短视频

1. 图片生成完成后，点击分镜的【生成视频】
2. 选择 Video 模型
3. 设置时长 5 秒，运动强度"中等"
4. 等待视频生成
5. 预览生成的短视频片段

#### 第 9 步：合成完整视频

1. 进入【视频合成】
2. 按顺序勾选所有分镜的短视频
3. 设置合成参数：
   - 分辨率：1080p
   - 帧率：30fps
   - 转场：淡入淡出
   - 背景音乐：上传轻快的夏日音乐
4. 点击【开始合成】
5. 等待约 2-5 分钟

#### 第 10 步：下载与发布

1. 合成完成后，在【完整视频】列表中找到成品
2. 点击【预览】确认效果
3. 点击【下载】保存 MP4 文件
4. 视频可直接用于：
   - 抖音 / 快手 / 视频号发布
   - 电商平台商品详情页
   - 线下门店播放

## 12. 常见问题与故障排查

### 12.1 登录相关问题

#### Q：忘记密码怎么办？
**A**：请联系系统管理员重置密码。管理员可在【用户管理】中找到您的账号，点击【重置密码】。

#### Q：提示"账号已被禁用"？
**A**：您的账号可能被管理员禁用，请联系管理员确认账号状态。

#### Q：登录后很快自动退出？
**A**：可能是浏览器 Cookie 被禁用，请检查浏览器设置，确保允许网站保存 Cookie。

### 12.2 剧本与分集相关问题

#### Q：AI 分集结果不符合预期？
**A**：
- 检查剧本内容是否足够详细
- 尝试在剧本中明确标注场景分界（如"【场景一】"、"【场景二】"）
- 分集后手动调整分集内容

#### Q：分集任务一直显示"处理中"？
**A**：
- AI 分集是异步任务，通常需要 1-3 分钟
- 如果超过 10 分钟仍未完成，可能是模型服务异常
- 请联系管理员检查模型网关状态

### 12.3 图片生成相关问题

#### Q：图片生成失败？
**A**：
1. 检查分镜是否已关联提示词
2. 检查 Image 模型是否在线（管理员可在【模型管理】中查看）
3. 检查提示词是否包含违规内容
4. 尝试简化提示词后重新生成

#### Q：生成的图片质量不佳？
**A**：
- 优化提示词，增加画质描述（如"4K、高清、精细细节"）
- 尝试更换 Image 模型
- 在提示词中指定艺术风格
- 使用【风格库】统一画面风格

#### Q：图片生成很慢？
**A**：
- 图片生成依赖 AI 模型服务，速度受模型提供商影响
- 高峰期可能需要排队等待
- 建议非高峰时段批量生成

### 12.4 视频生成相关问题

#### Q：短视频生成失败？
**A**：
1. 确认分镜已生成并选中了最终图片
2. 检查 Video 模型是否在线
3. 检查图片格式是否支持（JPG/PNG）

#### Q：合成的视频没有声音？
**A**：
- 确认合成时选择了背景音乐或上传了音频
- 检查音频文件格式（支持 MP3、WAV、AAC）
- 确认音频文件未损坏

#### Q：视频合成失败？
**A**：
1. 检查所有片段是否都成功生成
2. 检查存储空间是否充足
3. 检查 FFmpeg 服务是否正常运行（联系管理员）

### 12.5 进度与状态相关问题

#### Q：任务进度不更新？
**A**：
- 尝试刷新页面
- 检查浏览器控制台是否有 WebSocket 连接错误
- 可能是网络不稳定导致推送中断，刷新页面即可恢复

#### Q：流水线执行卡在某一节点？
**A**：
1. 点击该节点查看详细日志
2. 检查前置节点是否成功完成
3. 检查该节点所需的模型是否可用
4. 可手动重试该节点或重新执行流水线

### 12.6 权限相关问题

#### Q：看不到某些菜单？
**A**：您的角色权限不足，请联系管理员分配相应权限。

#### Q：无法编辑某个项目？
**A**：
- 确认您是该项目成员
- 确认您的角色具有编辑权限
- 项目创建者或管理员可以修改成员权限

### 12.7 性能与优化建议

| 问题 | 建议 |
|------|------|
| 页面加载慢 | 检查网络连接，清除浏览器缓存 |
| 批量生成卡顿 | 减少同时生成的数量，分批处理 |
| 视频文件太大 | 合成时选择较低分辨率（如 720p）|
| 存储空间不足 | 删除不需要的历史文件，联系管理员扩容 |

## 13. 术语表

| 术语 | 说明 |
|------|------|
| **AI 分集** | 利用大语言模型将完整剧本自动拆分为多个独立场景/段落的过程 |

| **分集** | 剧本拆分后的独立场景或段落，对应视频中的一个片段 |
| **分镜** | 视频制作中的画面规划，描述每个镜头的画面内容、时长、景别等 |
| **风格库** | 存放视觉风格模板的地方，用于统一视频的视觉效果 |
| **提示词（Prompt）** | 用于指导 AI 生成内容的文字描述，越详细效果越好 |
| **流水线（Pipeline）** | 可自定义的自动化工作流，将创作步骤串联自动执行 |
| **LiteLLM** | 平台对接的 AI 模型统一网关，支持调用多种大模型 |
| **模型网关** | 统一管理 AI 模型调用的中间层，负责请求转发和负载均衡 |
| **对象存储** | 用于存放上传文件和生成资源的云存储服务（如 S3、MinIO）|
| **剧本** | 视频的文字脚本，包含场景描述、对话、旁白等内容 |
| **短视频** | 由 AI 根据单张图片生成的 3-10 秒动态视频片段 |
| **完整视频** | 将多个短视频片段合成后的最终成品视频 |
| **WebSocket** | 一种网络通信协议，用于实时推送任务进度到页面 |
| **Image 模型** | 用于生成图片的 AI 模型，如 Stable Diffusion、DALL-E |
| **Video 模型** | 用于将图片转化为视频的 AI 模型，如 Runway、Pika |
| **Text 模型** | 用于文本生成的大语言模型，如 GPT-4、Claude |
| **Token** | AI 模型处理文本时的计费单位，通常 1 个汉字约等于 1-2 个 Token |
| **RBAC** | 基于角色的访问控制，通过角色分配用户权限 |
| **GORM** | Go 语言的数据库 ORM 框架，用于数据库操作 |
| **Redis** | 内存数据库，用于缓存和消息队列 |
